# Getting help

- **Something is broken:** open a [bug report](https://github.com/AndysTMC/Little-Later/issues/new?template=bug_report.yml). Include your browser and version and the Little Later version from `chrome://extensions`.
- **An idea:** open a [feature request](https://github.com/AndysTMC/Little-Later/issues/new?template=feature_request.yml).
- **A question:** search [existing issues](https://github.com/AndysTMC/Little-Later/issues?q=is%3Aissue) first; if nothing answers it, open a feature request that says what you were trying to do.
- **A security problem:** follow [SECURITY.md](./SECURITY.md). Do not open a public issue.

Only the latest release is supported. Little Later is maintained in spare time, so replies can take a few days.
